# Resolución de Algoritmos y Estructuras de Datos

Este repositorio contiene una colección de desafíos lógicos y matemáticos desarrollados en **Python**, enfocados en optimizar la resolución de problemas mediante estructuras de datos eficientes como diccionarios, listas enlazadas y búsquedas binarias.

## Tecnologías y Conceptos Aplicados
* **Lenguaje:** Python 3.x
* **Estructuras de Datos:** Diccionarios (Hash Maps), Listas Enlazadas (Linked Lists), Arreglos dinámicos.
* **Algoritmos:** Búsqueda Binaria (Binary Search), Algoritmos de ordenamiento, punteros lógicos y recursividad.

## Índice de Actividades

* **01. Contador de Elementos Únicos:** Uso de diccionarios para mapear frecuencias y calcular valores únicos en colecciones de datos lineales.
* **02. Inversión de Lista Enlazada:** Implementación de enfoques iterativos y recursivos para la manipulación de punteros en estructuras de datos dinámicas.
* **03. Validador de Números Palíndromos:** Algoritmo matemático para evaluar simetría numérica sin recurrir a conversiones de cadenas de texto (strings).
* **04. Plus One (Incremento de Arreglos):** Manejo lógico de acarreos dentro de vectores numéricos procesados de derecha a izquierda.
* **05. Búsqueda de Rango en Arreglos:** Implementación avanzada de Búsqueda Binaria para encontrar la primera y última posición de un elemento en tiempo O(log n).
* **06. Siguiente Permutación:** Algoritmo de ordenamiento combinatorio basado en el pivoteo e inversión de sub-arreglos.
* **07. Conversor de Números Romanos a Enteros:** Análisis secuencial de caracteres y aplicación de lógica condicional sustractiva mediante diccionarios clave-valor.
* **08. Two Sum (Suma de Dos Números):** Solución óptima en tiempo O(n) utilizando un Hash Map para almacenar complementos numéricos.

## Cómo Ejecutar las Pruebas
Cada script incluye sus propios casos de prueba locales integrados. Puedes ejecutar cualquiera de ellos directamente desde la consola:

```bash
python 01_contar_elementos_unicos/solution.py
```
